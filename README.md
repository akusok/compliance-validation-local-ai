# Compliance validation with local AI

Experimental solution to a realistic problem that involves "soft" functions running with tiny local AI models, and is fully developed with small local AI models runnable on a regular macbook.

Features:

- create reliable AI workflow for a repeatable realistic task
- compressed context representation, management
- workflow following and recovery
- token efficiency, small AI model adaptation
